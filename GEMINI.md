### Database Migration Enforcement
The application now enforces that the database schema version matches `REQUIRED_DB_VERSION` in `.env`.
- **Logic**: Checked in `PrismaService.onModuleInit()`.
- **Action**: If versions don't match, `npx prisma migrate deploy` is executed automatically.
- **Criticality**: If the migration fails, the application will terminate to prevent data corruption or runtime errors.
